# vermeuip.com.br Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Site em português, limpo, que mostra o IP do visitante e oferece teste de portas, consulta DNS, whois e teste de velocidade, hospedado em cPanel.

**Architecture:** Página única `index.php` (SSR do IP) + abas em JS puro que chamam endpoints PHP em `public/api/`. Lógica em classes PHP pequenas em `public/_lib/` (bloqueada por `.htaccess`), testadas com PHPUnit. Sem build no servidor.

**Tech Stack:** PHP 8.x, HTML/CSS/JS puro, PHPUnit, `maxmind-db/reader` (leitor puro PHP de `.mmdb`), DB-IP Lite (cidade + ASN), `@cloudflare/speedtest` (bundle vendorizado), LibreSpeed (backend PHP).

**Spec:** `docs/superpowers/specs/2026-10-23-vermeuip-design.md`. Protótipo visual aprovado: `.superpowers/brainstorm/2545-1792738510/content/prototipos.html` (aba "A · Abas").

## Global Constraints

- Idioma da interface: português do Brasil. Aparência clara, minimalista, fonte do sistema, responsiva (celular); segue o tema do sistema (claro/escuro), padrão claro.
- PHP 8 em cPanel compartilhado: sem Node, sem processos persistentes, sem build no servidor; `vendor/` vai commitado.
- Nenhum anúncio, sem login, sem histórico, sem logs próprios de IP.
- O IP vem de `REMOTE_ADDR` (cabeçalhos de proxy só se `TRUSTED_PROXIES` configurado); nunca de serviço externo chamado do navegador.
- Teste de portas: só no IP do próprio visitante, porta 1–65535, timeout curto, com limite de taxa por IP; resultado "fechada ou filtrada" com aviso (CGNAT/firewall).
- Bloquear IPs privados/reservados/loopback em qualquer entrada (DNS, whois, portas).
- DNS: tipos A, AAAA, MX, TXT, NS, CNAME, SOA, mostrando TTL. Whois: RDAP (`rdap.registro.br` para `.br`, bootstrap RDAP para os demais).
- Geolocalização: base local DB-IP Lite (atribuição no rodapé), sempre rotulada "aproximada"; se ISP/ASN vier vazio, mostrar só IP e localização.
- Velocidade: `@cloudflare/speedtest` (padrão) e LibreSpeed (plano B) atrás de `SPEED_ENGINE` (`'cloudflare'` | `'librespeed'`).
- Clarity (projeto `z23oq7eebz`) sempre carregado no `<head>`, sem banner de consentimento; elementos que exibem o IP levam `data-clarity-mask="true"`.
- Rodapé: privacidade curta, menção ao Clarity/cookies e ao teste de velocidade (Cloudflare), atribuição DB-IP, contato `contato@vermeuip.com.br`.
- Link "Ver no mapa" abre OpenStreetMap nas coordenadas; sem mapa embutido.
- O IP deve estar na primeira resposta do servidor; localização/provedor chegam depois por `api/geo.php`.

## Review Focus

- IP do visitante é `127.0.0.1` ou privado (ambiente local): página renderiza sem erro e geo mostra "indisponível".
- `X-Forwarded-For` forjado por visitante: ignorado quando `TRUSTED_PROXIES` está vazio.
- Domínio digitado como URL (`https://Exemplo.com/path`), com maiúsculas, ponto final ou IDN: normalizado antes de DNS/whois; IP literal ou `localhost` rejeitado.
- Porta `0`, `65536`, vazia ou não numérica: rejeitada com mensagem em português.
- Limite de taxa estourado: HTTP 429 com JSON `{"erro": "..."}` em português, e a aba mostra a mensagem.
- Sem PTR ou sem geo para o IP: campos mostram "—", nunca erro.
- Host bloqueia conexões de saída: teste de portas responde erro claro (não "fechada").
